# Changelog

## 0.3.0

- titulo(): el texto en mayusculas de titulo, sin tocar las menudas
- resume(): el texto recortado por la ultima palabra que cabe
- Los tests corren en GitHub Actions

## 0.2.0

- sin_acentos(): el texto sin tildes ni dieresis
- Type hints en la API publica
- Docstring de modulo y __all__

## 0.1.0

- envuelve(): el texto partido en lineas de `ancho` como maximo
- sangra(): el texto con `prefijo` delante de cada linea con contenido
- Tests con pytest
